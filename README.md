# Gamebrary

> Open source tool to organize video game collections.

---

## ⚠️ Project Status Update

Gamebrary is no longer accessible via **gamebrary.com**.

This project started as a fun side project and, while it wasn’t updated as frequently as I would have liked, it grew into something really special.

Over time, Gamebrary reached **3,000+ users**, which is honestly amazing for something built and maintained in spare time. Huge thanks to everyone who used it, shared it, and contributed along the way 🙌

---

## 🧩 Still Available

Gamebrary is still fully accessible:

- Run it locally from this open source repo
- Or use the hosted version here:  
  👉 https://gamebrary-8c736.web.app/

---

## 👋 Farewell (for now)

Gamebrary has been a great ride. It taught me a lot, connected me with awesome people, and helped shape how I think about building products.

While I’m shifting focus to other projects for now, this likely isn’t the end. There’s a good chance Gamebrary comes back in a new and improved form down the road.

Until then — thank you for being part of it ❤️

— Roman
